# Security Policy

Please report vulnerabilities through GitHub Security Advisories for this
repository. Do not put exploit details, credentials, signing material, private
device logs, recordings, or personal data in a public issue.

If private reporting is temporarily unavailable, open a minimal issue asking a
maintainer to contact you. Include no sensitive details in that issue.

Security fixes are assessed across Denzic Platform, Listener Type, and Listener
Firmware because a shared protocol defect may require coordinated host and
device releases.
