# Support

Use this repository for defects in shared protocols, portable state machines,
generators, or compatibility checks.

Use [Listener Type](https://github.com/Listener-ai-Macau/Listener-Type/issues)
for desktop UI, recognition, writing, insertion, or Windows integration. Use
[Listener Firmware](https://github.com/Listener-ai-Macau/Listener-Firmware/issues)
for board behavior, capture hardware, BLE transport, physical controls, power,
LEDs, or device OTA integration.

A useful report includes the affected capability and contract version, the
host and firmware revisions, exact reproduction steps, expected and actual
state transitions, and the smallest redacted log or test case that demonstrates
the problem. Remove credentials, personal data, recordings, transcripts, and
device identifiers before posting.

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
